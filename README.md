# Nature of roots of Quadratic Equation

A python program that determines the nature of the rootsof the quadratic equation of the form:

ax² + bx + c = 0

## Features
- Accepts values of a, b and c
- Speaks instructions using pyttsx3
- Displays the equation
- Determins whether the roots are:
    - Real and distinct
    - Real and equal
    - Imaginary

## Requirements

- Python
- pyttsx3

Install pyttsx3:

'''bash
pip install pyttsx3
'''

## Run

'''bash
python quadratic_roots.py
